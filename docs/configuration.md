# Configuration

Here you can find all available configuration options using ENV variables.

## Settings

OwnTinfoil HTTP shop and optional bot synchronization settings.

Environment variables override the project .env file. Bot synchronization
requires both BOT_URL and BOT_KEY; the local shop works without them.

| Name              | Type      | Default                                                                                                                                      | Description                                                                                                                                                                                                                                                                   | Example                                      |
|-------------------|-----------|----------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------|
| `NPS_DIR`         | `Path`    | `"NPSdir"`                                                                                                                                   | Directory containing files served by the HTTP shop, including subdirectories. Created on server startup. Docker uses /nps; the NPSdir spelling is retained for compatibility.                                                                                                 | `"./NPSdir"`, `"/nps"`                       |
| `TORRENT_DIR`     | `Path`    | `"TORRENTdir"`                                                                                                                               | Directory where bot torrent files are saved for the torrent client's watch folder. Created on server startup. Docker shares /torrents with Transmission's /watch.                                                                                                             | `"./TORRENTdir"`, `"/torrents"`              |
| `BOT_KEY`         | `string`  | `""`                                                                                                                                         | Bot synchronization key used as the HTTP Basic Auth password for username user. Leave empty to disable synchronization. Leading and trailing whitespace is removed.                                                                                                           | `"replace-with-your-bot-key"`                |
| `BOT_URL`         | `string`  | `""`                                                                                                                                         | Base HTTP or HTTPS URL of the bot's torrent directory, including its port if needed. Set together with BOT_KEY to enable synchronization. Leave empty for a standalone local shop.                                                                                            | `"http://bot.example.com:8878/"`             |
| `HOST`            | `string`  | `"0.0.0.0"`                                                                                                                                  | Address on which the HTTP server listens. Use 0.0.0.0 for LAN or Docker access, or 127.0.0.1 for this computer only. In Tinfoil, enter the server's reachable LAN address.                                                                                                    | `"0.0.0.0"`, `"127.0.0.1"`                   |
| `PORT`            | `integer` | `8080`                                                                                                                                       | HTTP server listening port, from 1 to 65535. Docker publishes container port 8080; keep this value at 8080 unless you also change the container port mapping.                                                                                                                 | `8080`, `8090`                               |
| `HTTP_AUTH_USERS` | `object`  | `{}`                                                                                                                                         | Local shop HTTP Basic Auth users as a JSON object mapping usernames to passwords. An empty object disables authentication. HTTP_AUTH_USERS__username=password is also supported, as is the legacy HTTP_AUTH_USER_1=username:password format. These are separate from BOT_KEY. | `"{\"player\":\"replace-with-a-password\"}"` |
| `SUCCESS_MESSAGE` | `string`  | `"Please join telegram bot @Switch_library_bot (password 'marsel') - get games at maximum speed, before tinfoil shops and absolutely free!"` | Message included in the shop.tfl JSON response and displayed by Tinfoil.                                                                                                                                                                                                      | `"Welcome to my local library."`             |
